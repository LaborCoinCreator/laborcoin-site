# Current Site Build

## Authoritative baseline

This repository contains one current Revision 7.2 predeployment build. No superseded site folders, dated copies, backup files, or alternate active configurations are retained.

- All current HTML, JavaScript, CSS, PWA, image, attestation, and whitepaper files
- `whitepaper.md`, `whitepaper.html`, and `whitepaper.pdf` as the current approved whitepaper set

The current visual design and active site source files were not redesigned during this cleanup.
